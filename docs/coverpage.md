# 🌉 SwagProxy

> A self-updating, self-restarting dual-protocol (Java + Bedrock) proxy launcher

Downloads and boots Velocity with Geyser and Floodgate, then supervises it for life: auto-updating, scheduled restarts, and automatic crash rollback.
